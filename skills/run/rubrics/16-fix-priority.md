# Rubric 16 — Fix priority

Priority = severity × reach × ease.
- Severity 5: a Bock rejection trigger (typo, length, formatting/ATS failure, confidential info, untrue or untraceable claim). 4: six-second zone fails (headline/top third doesn't name the niche). 3: must-have keyword missing for a code with prevalence ≥50%. 2: bullet below 3 on rubric 17. 1: style.
- Reach: number of qualified niches the fix improves (1–10).
- Ease: 3 = rewrite only; 2 = needs a number the candidate must confirm; 1 = needs new evidence.
The summary shows the top 5 fixes; the full list is in each niche's fit chapter.
