# Rubric 14 — Employer opportunity score (per niche)

For each employer with a live posting (or ≥2 postings in 12 months) in the niche:
| Component | Weight |
|---|---|
| Posting-level fit (rubric 11 applied to that employer's postings) | 35 |
| Liveness (rubric 08, best posting) | 20 |
| Access path strength (rubric 15) / 3 | 20 |
| Pay (posting midpoint vs niche median, clipped 0.7–1.3 → 0–1) | 15 |
| Segment / stage match with revealed preferences | 10 |

List the top 15. An employer with liveness `likely_ghost` is listed below the line with "watch, don't apply".
