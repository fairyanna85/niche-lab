# Rubric 21 — Disclosure risk

Scan every ledger line. Default actions when the candidate cannot be asked:
| Type | Default |
|---|---|
| Named private individual | remove |
| Named public figure | keep only if the candidate's link to them is public; otherwise generalize ("a government minister") and add to Confirm |
| Named client | keep if a public case study or press release names the relationship; else generalize ("a top-5 US retailer") |
| Current employer non-public figures (revenue, headcount, budget) | convert to ranges or percentages; add to Confirm |
| Confidential project or codename | remove |
| Personal data beyond contact line (age, photo, marital status, ID numbers) | remove |
Disclosure findings appear in the report's Confirm list, never as "risky" commentary about the person.
