# Rubric 11 — Candidate fit to a niche

For each code with prevalence ≥20% in the niche:
- weight w = required share (postings coding 2) + 0.5 × mentioned share (coding 1)
- credit = 1.0 (grade 3), 0.75 (grade 2), 0 otherwise
- fit = Σ w·credit / Σ w  → 0–1

Coverage (for qualification) = share of codes with prevalence ≥50% where grade ≥2.
Status per code in the report: proven (grade 3), partial (grade 2), gap (grade ≤1 on a code with prevalence ≥50%), minor (grade ≤1, prevalence 20–50%).
Gap fixes must be one of: surface existing evidence (ledger line exists but is buried), add a placeholder for a number the candidate must supply, or build new evidence (project, certification, public work sample) with a time estimate. Never invent experience.
